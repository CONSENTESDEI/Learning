#### 1.2.2 算法

>- **有监督学习**
>
>  - 训练集有特征有标签
>  - 定义：输入数据由特征值和目标值组成，训练数据有标签
>  - 数据集：需要标注数据的标签/目标
>
>   **有监督标签连续是回归，不连续分类**
>
>  - **分类问题**：目标值不连续
>  - **回归问题**：目标值连续
>
>
>
>
>- **无监督学习**
>
>  - 训练集有特征无标签
>
>  - 定义：输入数据无标签，样本数据类别未知，根据样本间的相似性，对样本集聚类，发现事物内部结构和相互关系，产生聚类
>
>
>
>- **半监督学习**
>
>  - 有特征部分有标签
>
>  
>
>  - **纯半监督**
>
>    - 参考有标签的数据训练给无标签的打标签，大幅降低标记成本
>
>    - 工作原理
>
>      专家标注少量数据
>
>      利用给数据套用未标注的数据
>
>      对比专家分类结果和模型分类结果优化模型
>
>
>
>
> - **直推学习**：把所有数据进行训练，找出无标记的
>
>
>
>- **强化学习**
>  - 属于深度学习
>  - 机器学习重要分支

### 1.4 特征工程入门

**特征工程目的**：<u>利用专业背景知识和技巧处理数据，让机器学习算法效果更好</u>

**数据和特征决定机器学习的上限，模型和算法是逼近这个上限**

#### 1.4.1 **步骤**：

>1. 特征提取：原始数据中提取与任务相关的特征，构成特征向量，<u>会改变原数据</u>
>2. **特征预处理**：防止因量纲的问题导致特征对模型的影响差距过大，鲁棒性较差。归一化：全压缩到0-1，x' = (当前值 - 最小值) / (最大值 - 最小值)，标准化
>3. 特征降维：降低数据维度，<u>不改变原数据</u>
>4. 特征选取：选择与任务直接相关的，<u>不改变原数据</u>
>5. 特征组合：多个特征合并成一个特征



### 1.5 模型拟合问题

**拟合fitting**：模型对样本点的你和情况，在训练集和测试集上的表现情况

**过**：训练表示好，测试不好，模型过复杂、数据不纯、训练数据过少

**欠**：训练测试都不好，模型过简单，增加特征复杂化模型

**泛化**：模型在新数据表现好坏，模型的拟合情况

**奥卡姆剃刀**：有多个相同泛化误差的模型，简单模型更可取

### 1.7 KNN算法

#### 1.7.1 简介

> 如何一个样本在特征空间中的K个最相似的样本中的大多数属于某一类别，该样本也属于该类别，距离越近相似度越高
>
> 欧氏距离 = 对应维度差值平方和，开平方根，点间距离公式
>
> 还有其他算法



>**k值小会过拟合**
>
>- 用较小邻域中的训练实例进行预测
>
>- 易受异常点影响
>- 过小整体模型复杂
>
>**k值大会欠拟合**
>
>- 用较大邻域中的训练实例进行预测
>- 受样本均衡的问题
>- 过大整体模型简单
>
>
>
>k = n无论输入实实例是什么，只会按训练集中最多的类别进行预测，受样本均衡影响
>
>解决分类回归问题



#### 1.7.2 分类流程

>**分类回归异同点**:
>
>- 有监督，有特有标
>- 连续回归，不连续分类
>- 分类是投票，回归是均值



>**流程**
>
>- 共有部分
> 1. 计算未知样本到每个训练样本的距离
> 2. 将训练样本距离按升序排
> 3. 取出距离最近的K个训练样本呢
>
>
>
>- **分类流程**
> - 进行多数表决，统计K个样本中哪个类别样本个数最多
> - 将未知的样本归属到出现次数最多的类别
>
>```python
>"""
>KNN算法介绍(K Nearest Neighbors)，K近邻算法
>   原理:
>       基于 欧式距离 计算 测试集 和 每个训练集之间的距离，然后根据距离升序排列，找到最近的K个样本，
>       基于这K个样本投票，票数多的做为最终预测结果 -> 分类
>       基于K个样本计算平均值，最为最终预测结果 -> 回归
>
>   实验思路：
>       1. 分类
>           适用于：有特有标，且标签不连续
>       2. 回归
>           适用于：有特有标，且标签连续
>
>KNN分类算法如下：
>   1. 计算未知样本到每个训练样本的距离
>   2. 将训练样本距离按升序排
>   3. 取出距离最近的K个训练样本呢
>   4. 进行多数表决，统计K个样本中哪个类别样本个数最多
>   5. 将未知的样本归属到出现次数最多的类别
>
>代码实现思路：
>   1. 导包
>   2. 准备数据集（训练集、测试集）
>   3. 创建模型(KNN 分类模型)对象
>   4. 模型训练
>   5. 模型预测
>"""
># 1. 导包
>from sklearn.neighbors import KNeighborsClassifier
>
># 2. 准备数据集（训练集、测试集）
># neighbors：最近邻的邻居数量
>x_train = [[0], [1], [2], [3]]  #训练集的特征数据，因为特征可以有个多个，所以是个二维数组
>y_train = [0, 0, 1, 1]          #训练集的标签数据，因为标签是离散的，随意是个一维数组
>x_test = [[5]]                  #测试集的特征数据
>
># 3. 创建模型( KNN 分类模型)对象
># estimator：估计器，模型对象，也可用变量名 model 做接收
>estimator = KNeighborsClassifier(n_neighbors=1)
>
># 4. 模型训练
># 传入：训练集特征和标签
>estimator.fit(x_train, y_train)
>
># 5. 模型预测
># 传入：测试集特征，获取到预测值
>y_pred = estimator.predict(x_test)
>
># 6. 打印预测结果
>print(f'预测值为：{y_pred}')
>```
>
>
>
>- **回归流程**
> - 把K个样本的目标值计算其平均值
> - 平均值作为未知样本预测的值
>
>```python

>   实验思路：
>       1. 分类
>           适用于：有特有标，且标签不连续
>       2. 回归
>           适用于：有特有标，且标签连续

>KNN回归算法如下：

#### 1.7.4 距离度量

> -  **欧氏距离：**
>
>   直观距离度量
>
>   两点之间的距离
>
>   **各维度差值的平方和，开根**
>   $$
>   d_2(\mathbf{x}, \mathbf{y}) = \sqrt{\sum_{i=1}^{n} (x_i - y_i)^2}
>   $$
>
> 
>
> - **曼哈顿距离**：
>
>   城市街区距离
>
>   只能横平竖直走
>
>   **对应维度差值绝对值，求和**
>   $$
>   d_1(\mathbf{x}, \mathbf{y}) = \sum_{i=1}^{n} |x_i - y_i|
>   $$
>
> 
>
> - **切比雪夫距离**：
>
>   形似国际象棋，可以斜着走
>
>   **对应维度差值绝对值，求最大值**
>   $$
>   d_\infty(\mathbf{x}, \mathbf{y}) = \max_{i} |x_i - y_i|
>   $$
>
> 
>
> - **闵可夫斯基距离**：
>
>   闵氏距离
>
>   是一种总结
>   $$
>   d_p(\mathbf{x}, \mathbf{y}) = \left( \sum_{i=1}^{n} |x_i - y_i|^p \right)^{1/p}, \quad p \geq 1
>   $$



#### 1.7.6 特征预处理

**归一化、标准化目的**：特征的单位或大小相差较大，或者某特征方差比其他特征大出多个量级，容易影响目标

> - **归一化**
>
>   **弊端**：易受到最值的影响
>
>   **适用于处理小数据集**
>
> 
>
>     对原数据进行变换使其映射到 [min, max] 内
>
>   映射到 [0, 1] 内：
>$$
>   x_{\text{norm}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}
> $$
>   映射到 [a, b] 内：
> $$
>   x_{\text{norm}} = a + \frac{(x - x_{\min})(b - a)}{x_{\max} - x_{\min}}
> $$
> 
>   ```
>  """
>   特征预处理——归一化
>   """
> 
>   # 导包
>     from sklearn.preprocessing import MinMaxScaler
> 
>   # 1. 准备数据
>     x_train = [[40, 2, 10, 65], [60, 15, 34, 46], [77, 38, 57, 29]]
> 
>   # 2. 创建归一化对象
>     transfer1 = MinMaxScaler()  # 默认 [0, 1]
>   transfer2 = MinMaxScaler(feature_range=(2, 5))  # 指定 [2, 5]
> 
>   # 3. 对原数据集进行归一化操作
>     x_train_new_1 = transfer1.fit_transform(x_train)
>   x_train_new_2 = transfer2.fit_transform(x_train)
> 
>   # 4. 打印数据
>     print(f"归一化后的数据集_1为：\n{x_train_new_1}")
>   print(f"归一化后的数据集_2为：\n{x_train_new_2}")
>   ```



> - **标准化**
>
>   通过对原始数据进行标准化，转换为均值为 0 标准差为 1 的标准正态分布
>
>   - **正态分布**：
>
>     也称 **高斯分布**，记作 **N(μ, σ)**
>
>     **均值μ**：决定其位置
>
>     **标准差σ**：决定分布幅度
>
>     **μ = 0, σ = 1** 时是标准正态分布
>
> 
>
>   - **方差σ^2^** 是衡量一组数据时 **离散程度的度量**
>
>     M 为均值μ，n 为数据总数
>     $$
>     \sigma^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - M)^2
>     $$
>
> 
>
>   - **标准差σ** 是方差开根
>     $$
>     \sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i - M)^2}
>     $$
>
> 
>
>   - N(0, 1) 的 **3σ法则**（68-95-88.7 法则）
>
> 
>
>   ```python
>   """
>   标准化
> 
>   方差：该 列 每个值和该列 均值 的差的 平方和 的 平均值
>   标准差：方差开平方根
>   """
> 
>   # 导包
>   from sklearn.preprocessing import StandardScaler    # 标准化对象
> 
>   # 1. 准备数据
>   x_train = [[40, 2, 10, 65], [60, 15, 34, 46], [77, 38, 57, 29]]
> 
>   # 2. 创建标准化对象
>   transfer1 = StandardScaler()  # 均值、方差、标准差是数据固有属性，所以不能限定范围
> 
>   # 3. 对原数据集进行标准化操作
>   x_train_new_1 = transfer1.fit_transform(x_train)
> 
>   # 4. 打印数据
>   print(f"标准化后的数据集_1为：\n{x_train_new_1}")
> 
>   # 5. 打印数据集的均值和方差
>   print(f'数据集的_1均值为{transfer1.mean_}；\n方差为；{transfer1.var_}；\n标准差为{transfer1.scale_}')
>   ```
>   



>|          | 归一化                                                       | 标准化                                                       |
>| -------- | :----------------------------------------------------------- | ------------------------------------------------------------ |
>| 缺点     | 如果出现异常点，影响了 **最值**，那么结果必然发生改变。**最值** 易受异常点影响，**鲁棒性** 较差 | 如果出现异常点，由于具有一点的数据量，少量的异常点对于平均值的影响不大 |
>| 应用场景 | **传统精确小数据场景**                                       | **现代嘈杂大数据场景**                                       |
